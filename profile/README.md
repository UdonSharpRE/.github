# 已存档

过去我花费大量时间沉浸其中，我在制作这一系列开源软件时还是相当有兴趣的。但是我不得不承认，做好开源软件绝非易事，尤其是在VRChat RE这种几乎灭绝的领域中。

我承认过去几年内，在开源软件上尝试的失败使得我的内心受到了打击，但是我最初停止更新本组织内容的原因是因为当时发生了一些圈子内的事情，我不得不停止继续开源更加前沿的工具/内容。

后来人也有针对 UdonSharp 研究，很高兴看到有继任者。我希望后来者在制作教程或者提供信息时能够避免'知识的诅咒'，解释起来有点复杂，你可以问问LLM。

简而言之，我在本组织下写下的很多内容都有过调整来避免没有解释某些概念而造成初学者的困惑，这有助于让初学者容易明白，能够勾起他们的兴趣，或许某个读完这篇的人对逆向工程感到兴趣，从而成为未来逆向工程领域里面一个重要的人。

而这样做的代价就是：及其容易在内行人眼里看起来好像是"只知道皮毛"而已，仅仅是因为你"过分的"解释太过于基础的东西。虽然我不知道为什么要无端地如此不尊重别人，这可能和中文互联网的戾气离不开关系。

## UdonSharp Reverse Engineering

本库的发布主要用于针对游戏 VRChat 中的地图脚本 UdonSharp，一种类似C#的编译型虚拟机语言的逆向工程。

## 从这里开始

[点我](https://github.com/UdonSharpRE/Manual)

## 这里都有什么？

任何有关 UdonSharp 的原理知识你都可以在这里看到，我们希望开发者了解 UdonSharp 是如何工作的。除此之外，我们还提供反汇编/反编译工具

## 你为什么要这样做？

我很乐意和别人分享知识。

## 您是否知道这会对别人的地图产生破坏性？

这件事情和我无关，这是VRChat的责任，你应该向他们狗叫。

## 这属于游戏外挂吧？这违反VRChat ToS吧？

算是吧。未满13岁的人玩游戏也违反VRChat ToS。
